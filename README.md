# Take It Easy Project 🎮

This project is a command-line implementation of the board game **Take It Easy**.

Developed as part of the Software development course at the University of Trieste.

---

## ✅ Features

- Full tile system (27 unique tiles)
- Board placement (19 positions)
- Score calculation in all 3 directions:
    - Horizontal
    - Diagonal Left
    - Diagonal Right
- Playable game loop in terminal
- Unit tests with JUnit 5
- Continuous Integration with GitHub Actions

---
